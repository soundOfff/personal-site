The default instinct when an LLM feature is too slow or too expensive is to reach
for a bigger budget — more tokens, a larger model, a higher tier. The cheaper move
is almost always to **route**: classify the request, then dispatch it to the
smallest model that still clears the eval bar.

## The setup

We sat a classify-then-dispatch router in front of three providers — OpenAI, Groq
and OpenRouter — and let it pick per request.

```ts
const cls = classify(prompt); // extractive | structured | reasoning | creative
const model = cheapestThatClears(cls); // walk the catalog, cheapest first
const result = await dispatch(model, prompt);
```

## The catch

Routing only works if your evals are honest. If a class's bar is too low, you ship
quality regressions invisibly. That is why [evals are contracts](/blog/rate-limiting-inference) —
the routing decision is only as trustworthy as the test that gates it.
