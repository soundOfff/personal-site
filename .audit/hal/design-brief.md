Read grounding.md and real source. Produce one candidate sketch in designated file. Compare structurally distinct boundaries as appropriate. Do not edit source. Do not spawn agents.

Rubric, score each 0-3: cinematic usability and accessibility; coherent small API with one state owner; request budget + validation; scroll/reel cleanup and invisible focus safety; scope and maintainability. Prefer deep small API over transport plumbing.
