# Five points of view

The photographed openings were removed after visual feedback: generated imagery felt artificial, and camera enlargement exposed raster detail. The replacement uses five separate Astro compositions, with HTML typography, SVG geometry and CSS materials. There is no background image, raster zoom or shared headline.

| Film                     | Composition                                                                              | Movement                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Parasite                 | Architectural section, cream paper above a dark basement                                 | Vertical descent through three floors, with a second line revealed underground |
| In the Mood for Love     | An intimate view through wet glass and foreground timber screens                         | Lateral tracking and foreground occlusion, with a reflected second composition |
| Blade Runner 2049        | A vector iris in extreme close-up                                                        | Scan across the iris, then a dissolve into an orange typographic frame         |
| The Grand Budapest Hotel | Overhead correspondence: guest register, architectural engraving, envelope and brass key | Papers separate and rotate independently while the camera holds                |
| 2001: A Space Odyssey    | HAL's lens, then a geometric eclipse and orbital diagram                                 | A match dissolve between circular subjects, followed by an orbital roll        |

The outer sticky viewport and scroll clock are shared. The scenes, typography, placements, pacing and motion are not. Scrolling remains native; navigation can jump directly into the portfolio. Mobile uses composed, taller layouts and a shorter scroll distance. Reduced motion shows the initial composition without extra scroll runway.

## Performance

- Removed all ten generated AVIFs and the image preload, about 683 KB of project assets.
- No new dependencies, remote media, fonts, canvas or WebGL.
- Deterministic SVG paths are generated by Astro at build time. Iris coordinates are rounded to a tenth of a viewBox unit.
- Only the active scene is displayed. Only its four phase variables are updated.
- One requested animation frame per scroll event, with geometry cached until resize; no idle JavaScript render loop.
- Movement uses transforms and opacity. Offscreen and hidden-tab work stops; unmount disconnects observers and cancels pending updates.
- Production build and visual browser iteration only, no automated tests, per the requested workflow.
