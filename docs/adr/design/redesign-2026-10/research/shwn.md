# shwn.design — research report

## 1. Identity
Shawn D'silva, 23, design engineer in Goa (X: @zzzzshawn). Next.js/Turbopack + Tailwind v4 + `motion` (framer) + MapLibre + number-flow + hand-rolled WebGL2. Concept in one sentence: a two-screen page that behaves like a desk of small physical gadgets — a living pond, one sentence you can restyle, a shelf of 13 working UI toys, a clock — where every control makes a sound.

## 2. Layout & structure
- Single centered column (~365px of text at 1440), page height 1807px. Whole site is authored at 1710px and scaled with `html{zoom:var(--site-scale)}`, `--site-scale = clamp(innerWidth/1710, .8, 1.5)` (only >=1024px and `pointer:fine`). Motion's `transformPagePoint` divides pointer coords by that scale so drags still work.
- Order: floating 2-icon nav pill -> 620x413 koi canvas -> "Hey," + 3-line intro -> horizontal rail of 13 prototype cards (352x384, `#f2f2f2`, squircle corners) with prev/next buttons -> footer "peace out" + live clock. No sections, no headings, no footer links.
- Reveal: every block has a `SLOT` index; delay = index x 100ms (pond 0, greeting 200, name 300, craft 400, contact 500, prototypes 600, footer 800). Each animates `opacity 0->1, scale 1.1->1, filter blur(20px)->0` (pond 40px) with `spring{bounce:0, duration:.8}` (hero 1.1s).
- /projects: three business-card-sized dark cards in a tilted pile, held by a pushpin, binder clip and a 3D cursor (webp props). Click -> card moves to the top, the pile fades (`html:has([data-write-up-open])` -> opacity 0, .3s), write-up below with tilted "polaroid" screenshots and handwritten Caveat captions. "back" (with a return-arrow glyph) to go back.

## 3. Typography
Public Sans 15px/500 for literally everything including the `h1` (the h1 *is* the sentence). Caveat (handwriting) for "design engineer" and captions; Playfair Display and Public Sans are the alternate choices in the toolbar; Geist Mono for the clock and URLs; Oleo Script/Aguafina Script loaded for prototypes. Hierarchy comes from weight/color flips, not size.

## 4. Color & surface
`--background:#fbfbfb`, `--foreground:#707070`, prototype surface `#f2f2f2`, single accent `--focus-ring:#fc6401` (orange, focus only). Hover-keyword colors `#3232ff / #b1035a / #f21e29`. Light only (`.dark` rules exist only inside prototypes with `data-theme="dark"`). Texture: `/assets/paper-texture.jpg` on the business-card tooltip, inline SVG `feTurbulence` noise (`baseFrequency .75`; anisotropic `0.0018 0.85` = brushed metal on project cards), `conic-gradient` vinyl sheen. Shadows soft and few (`0 2px 5px`, `0 4px 18px`, `0 8px 24px`). `corner-shape: squircle` with a JS `SquircleFallback` that draws clip-paths.

## 5. Motion inventory
- **Koi pond (hero)**: WebGL2 (`EXT_color_buffer_float`), ping-pong height-field ripple sim + caustics shader; fish with 22-point spine, 160-point trail, `fear`/`flee` state. Pointerdown on a fish -> `scare()` (speed bump, tail flick) + small splash; on water -> splash + drop + `disturb()`; drag -> a splash every 8px. Up to 12 sub-steps/frame; pauses when offscreen/hidden; adaptive resolution via frame-time median.
- **Hover cards** on words: "Shawn" -> square photo; "Goa" -> live MapLibre map of Goa; "@zzzzshawn" -> 3D-tilt business card (rotateX/Y motion values, `perspective:800px`, light spot at `--px/--py`). Open with `spring{420,28,.7}` (media) or `{520,32,.6}`; closeDelay 160ms (handle: open 220/close 260, 44px hit padding); a fixed overlay blurs the whole page behind.
- **Inline text editor**: "design engineer" sits in a Figma-style selection box (4 corner handles) with a toolbar anchored via CSS Anchor Positioning (`anchor-name:--trigger`, `position-anchor`, `anchor(--trigger bottom)`). Font dropdown uses a `layoutId` sliding hover highlight (`spring{520,32}`); choosing a font swaps the word with blur-out/in; B/I toggle `aria-pressed`; style menu swaps text gradients (Flat / Blue depth / Warm depth / Spectrum).
- **Craft paragraph group-hover**: keywords go bold + colored (`transition: color,font-weight .15s`) and three inline icons start CSS keyframe loops: `heart-icon-beat` (scale 1->1.04->1.1, cycle .4+.3+.4s) + `heart-icon-glow`, `building-icon-tower-stretch` (scaleY) + `building-icon-flag-flow` (`stroke-dashoffset` 110->-110 over 1.4s), `leaf-icon-hand-tap` + `leaf-icon-heart-wave` (`clip-path: circle()` reveal). All timings are CSS vars (`--heart-icon-beat1` etc.); nothing animates at rest.
- **Nav pill**: two grey circles (56 active / 37.6 idle, 54px apart) under an SVG goo filter (`feGaussianBlur 10.6` -> `feColorMatrix 30 -11.5` -> flood `#f2f2f2`); a white droplet travels between them with front/back radii that stretch and a blur peaking mid-flight (`1.5*sin(pi*u)`), driven by one spring motion value `{355,38}`; icons move with `{380,38}`. Optimistic: blob moves on click before the route changes.
- **Prototype rail**: native horizontal scroll (`scroll-snap-align:start` children, `scroll-padding-inline:max(.5rem,50% - 217px)`); vertical wheel is hijacked to horizontal (`deltaY*2.5`) unless a trackpad is detected (global capture listener flags small deltaY or any deltaX); prev/next `whileTap{scale:.9}`; cards mount lazily (IntersectionObserver `rootMargin 900px`).
- **Prototypes themselves**: Walkman (dot-matrix LCD, plays iTunes previews), Toolbar (style cycler with text morph), Folder, Wallet (`wallet-front/behind` keyframes: translateY -280px + z-index swap + scale 1.5), Review (3D blue card), Matrix (dot display, knob), TV (`miniTvFlicker/StaticMove/StaticFlicker` keyframes, hue-rotate/skew jitter), Dial (`spring{720,30,.5}` rotate, detent ticks), iPhone, Search, Account, Tabs, Vinyl (`turntable-spin 18s linear`).
- **Scroll-driven CSS**: `html` is `scroll-timeline-name:--drawer-body`; fixed top/bottom gradient + `backdrop-blur(2px)` overlays run `drawer-top-fade-in` over `animation-range: 0 6rem` and `drawer-bottom-fade-out` over the last 6rem — pure CSS, no JS.
- **Clock**: `number-flow-react` digits (900ms `linear()` spring easing; `scritto-text` for SSR); number-flow also drives the Dial %.
- Easings: Tailwind `cubic-bezier(.4,0,.2,1)`, `--ease-in-out-cubic`, `cubic-bezier(.215,.61,.355,1) .4s` for color, `cubic-bezier(.2,.9,.2,1) 75ms` for press; `prefers-reduced-motion` honored everywhere (reveal becomes .3s fade, whileTap removed).

## 6. Sound
Entirely synthesized with Web Audio — no sample files. A global `ButtonSounds` component (data attrs `data-cuelume-*`) installs capture-phase `pointerdown/keydown/click` listeners and auto-picks a preset per control: `nav a` -> *arrival*; `aria-expanded` true -> *tick*, false -> *scan*; `aria-haspopup=dialog` -> *bloom*; pressed/checked toggles -> *tick* (on) / *chime* (off); `role=tab` -> *page*; option/menuitem -> *chime*; label regex close/cancel/back/pause -> *tick*, next/prev -> *page*, play -> *ready*, search -> *scan*, send/submit/request -> *success*; default *pulse*. Opt-ins: `data-cuelume-hover` (pointerenter, mouse-only, 150ms throttle -> *chime*), `-press` -> *press*, `-release` -> *release*, `-toggle` -> *toggle*; `data-sound="<preset>"` overrides (fonts: Public Sans = *chime*, Caveat = *sparkle*, Playfair = *bloom*; styles: *page/ready/bloom/sparkle*); `data-sound="off"` mutes.
Engine: each preset = `masterGain` + layers of `{kind:"tone", waveform, frequency, glideTo, attack, decay, peak, offset}` or `{kind:"noise", filterType, filterFrequency, Q, ...}` with optional `shimmer` (feedback delay + lowpass, wet .1-.22), summed into a gain x4 -> `DynamicsCompressor(-8dB, knee 6, ratio 12, 2ms/80ms)`. Examples: *tick* = bandpass-5400Hz noise 18ms + 2600Hz sine 12ms; *success* = A5-C#6-E6 sines 60ms apart; *arrival* = 220->440Hz glide + E5/B5, ~340ms; *error* = 440->349Hz triangles. Nothing plays before `navigator.userActivation`. Prototypes add bespoke ones: Dial detents (triangle 1800->980Hz through highpass, 22ms, rate-limited 55ms), TV channel knob (square 920->500 + triangle 590->340 + bandpass noise). Walkman/Vinyl play 30s iTunes `.m4a` previews via `<audio preload=none>`.

## 7. Navigation & wayfinding
Two routes only; the gooey pill is the whole nav. No command palette, no shortcuts (Cmd+K, `/` do nothing), no progress indicator, no section anchors. Carousel arrows disable at ends; credit links "Recreated from @handle" on three cards; "back" inside write-ups. Wayfinding is deliberately minimal — the sound layer and hover cards do the orienting.

## 8. Signature moments
1. Tapping a koi and watching it bolt while the caustics ripple.
2. The bio sentence that is secretly a text editor — selection handles, anchored toolbar, and each font choice has its own chord.
3. The nav blob that stretches and blurs across like mercury, plus the realisation that *every* button on the page clicks, ticks or chimes.

## 9. STEAL LIST (for Tomas)
1. **Declarative synth sound layer, not samples.** Port the preset-bank idea: one `sound.ts` with `{layers:[{tone|noise...}], shimmer}` -> oscillator/noise graph -> compressor; one document-level capture listener that infers the cue from ARIA (`aria-expanded`, `aria-pressed`, `role=tab`, label regex). Zero assets, respects user activation, mute via `data-sound="off"`. Give the A2UI agent its own cues: *loading* while it thinks, *success* when a surface lands, *error* on refusal.
2. **Per-section reveal as SLOT x 100ms with blur.** Replace fade-ups with `opacity 0->1, scale 1.1->1, blur 20->0, spring bounce 0 .8s`, delay = rail index x 100ms. Reuse it when A2UI composes a surface: each generated card/table/timeline gets the next slot.
3. **Gooey rail indicator.** Tomas's 00-08 rail could have a metaball marker: active circle + travelling droplet under an SVG goo filter (`blur 10 -> colorMatrix 30/-11.5`), position from one spring motion value tied to the active section; blur peaks mid-travel. Pair with the *arrival* chord on section change.
4. **Inline-editable hero token.** Make "Fullstack · AI systems" a selectable token with an anchor-positioned toolbar (CSS `anchor-name`/`position-anchor`) that swaps Newsreader/Geist/JetBrains Mono, each with its own cue — a wink at the A2UI "agent picks the UI" idea.
5. **Hover cards on nouns.** "Rosario" -> MapLibre carto tile at low zoom in a 1:1 squircle; "Dex/Mint/Flagship" -> 3D-tilt card with a paper texture and `--px/--py` light spot; `spring{420,28,.7}`, 160ms close delay, backdrop blur of the page.
6. **Dot-matrix/number-flow live data.** Footer clock in JetBrains Mono via number-flow; extend to the A2UI quota counter and Mint's "2-3M users" stat so digits roll instead of pop.
7. **Edge fades as pure CSS scroll-driven animation.** `html{scroll-timeline-name}` + fixed gradient/blur overlays with `animation-range 0 6rem`; also apply inside the A2UI slideover console (that is literally what `--drawer-body` is for here).
8. **Physical-prop case studies.** /projects pile: cards with brushed-metal `feTurbulence`, pushpin/binder-clip props, handwritten Caveat annotations on screenshots. For Tomas: Newsreader italic as the "handwriting", amber pin instead of chrome.

## 10. Anti-patterns
- `html{zoom}` global scaling: breaks `vh`/pointer maths (he had to patch motion), blurs raster, and makes text 15px -> 12.6px at 1440.
- 15px for *everything* including h1: no scanning hierarchy; fine for 2 screens, fatal for 9 sections.
- Heavy hero: WebGL2 + float textures + 1.05MB MapLibre chunk on first paint; no reduced-data path.
- Carousel wheel hijack: surprising on mice; keep horizontal rails scroll-native.
- Sound on by default on every control with no visible toggle; Tomas should expose a mute (and remember it) since the A2UI console is already busy with motion.
- iTunes previews and recreated-from-X toys read as "fan page"; keep toys that serve the story (routing, scale, A2UI).

## 11. Verdict
This site is the strongest sound-and-micro-interaction reference in the set: a complete, inferable audio grammar bolted onto ordinary ARIA, and motion that always has a physical metaphor (goo, water, paper). For Tomas it points to a "quiet page, loud details" variant: keep the warm-paper, hairline, numbered-rail skeleton, but give the rail a mercury marker, give every control a synthesized cue, and make the A2UI playground the pond — the thing you poke and it reacts. Score: **8/10** of its DNA belongs in one variant (sound engine, reveal slots, goo indicator, hover cards); leave the zoom hack, single-size type and WebGL hero behind.
