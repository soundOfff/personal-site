// principles · how I build

01

Smallest model that passes

Capability is a budget, not a flex. Start at the bottom of the ladder and only climb when an eval forces you to.

02

Cache before you call

The cheapest token is the one you never send. Memoize aggressively; treat the model as the slow path.

03

Cap the blast radius

Every public endpoint gets a rate limit and a kill switch before it gets a launch tweet.

04

Evals are contracts

If a behaviour isn’t measured, it isn’t shipped. Write the contract down, then make it runnable.
