I’m a backend and systems engineer who likes the unglamorous middle of the stack — the routing, the caching, the limits that decide whether a feature is affordable. Currently looking for teams shipping LLM products that have to be cheap to be real.

This site is built with Astro and ships near-zero JavaScript. The playground is the single exception: a React island backed by a serverless function. Demo responses are cached at the edge; live mode is rate-limited and keys never leave the server. Read the build notes →
